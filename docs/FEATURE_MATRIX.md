# AUTOVERSE 3D — FEATURE AUDIT & PROVENANCE MATRIX (`docs/FEATURE_MATRIX.md`)

**Date:** 2026-11-18  
**Operating Standard:** Operating Contract v2 (§1.1 Truth and Evidence, §3 Phase 0)  
**Strict Provenance Taxonomy:**
- `CFD`: Output generated by a genuine numerical solver run (OpenFOAM `simpleFoam` / `pimpleFoam`).
- `ANALYTIC`: Engineering estimates derived from verified closed-form equations or published empirical data.
- `ILLUSTRATIVE`: Visual, aesthetic, or decorative representations; carries zero aerodynamic or physical engineering validity.

## 2. Decorative & Simulated-For-Show Audit

In accordance with Operating Contract v2 §1.1 and §3.3:
1. **Airflow / Particle Streams**:
   - Any animated WebGL ribbon or particle effect not driven by actual OpenFOAM velocity vector fields ($U_x, U_y, U_z$) must be explicitly badged as `ILLUSTRATIVE — AESTHETIC VISUALIZATION ONLY`.
   - Never display a drag coefficient ($C_d$) or downforce value alongside an illustrative animation unless derived from a verified run.
2. **Underglow & Sound Effects**:
   - Strictly relegated to Customization and Showroom modes; disabled in Engineering and Aerodynamics modes.
3. **Engineering Metrics Provenance Header**:
   - The HUD in 3D Studio, Engineering Mode, and Comparison Studio must permanently display the provenance badge of the active metric set:
     - `[PROVENANCE: CFD (OpenFOAM v11 - simpleFoam)]`
     - `[PROVENANCE: ANALYTIC (Empirical Estimation)]`
     - `[PROVENANCE: ILLUSTRATIVE (Visual Display)]`
